#
# SUT:    LCDDisplay built to use SPIDriver (-DROOL_SPIDRIVER -DLCDDISPLAY_NO_PWM)
# Area:   Module
# Class:  Functional
# Type:   Integration test
#
# The module is loaded in RISC OS Pyromaniac, whose SPIDriverEmulator provides an emulated ST7789
# panel on an SPI channel (branch spidriver-experiment of Pyromaniac). run-pyromaniac runs the
# module and, with --compare, checks the picture that the panel shows against the test sprite.
# Run with run-tests, which builds the module with those definitions first.

Group: LCDDisplay (SPIDriver): Panel

Command: $TOOL $ARGS
Replace: expect/replacements

Test: The panel is black when the module has started
Args: --compare black
Expect: expect/panel-black

Test: A sprite loaded is shown on the panel, pixel for pixel
Args: --compare sprite --command "LCDDisplayLoad testpanel"
Expect: expect/panel-sprite

Test: A panel with no colour inversion shows the sprite inverted, which the check notices
Args: --devices st7789:rotate=90 --compare sprite --command "LCDDisplayLoad testpanel"
Expect: expect/panel-inverted
RC: 1

Test: A panel mounted another way up shows the sprite turned, which the check notices
Args: --devices st7789:rotate=270,ips=1 --compare sprite --command "LCDDisplayLoad testpanel"
Expect: expect/panel-turned
RC: 1

Group: LCDDisplay (SPIDriver): Channel

Command: $TOOL $ARGS
Replace: expect/replacements

Test: The channel can be chosen by name
Args: --command "LCDDisplayChannel \"st7789 0\""
Expect: expect/channel-chosen

Test: A channel which is not there is refused
Args: --command "LCDDisplayChannel nonesuch"
Expect: expect/channel-missing
RC: 1

Test: The module does not start when there is no channel
Args: --devices ""
Expect: expect/channel-none
RC: 124

Test: The module does not start with a channel which has no command and data line
Args: --devices loopback
Expect: expect/channel-no-aux
RC: 124

Group: LCDDisplay (SPIDriver): Commands

Command: $TOOL $ARGS
Replace: expect/replacements

Test: The reset pin can be set
Args: --command "LCDDisplayReset 17"
Expect: expect/reset-pin

Test: The reset pin needs a number
Args: --command "LCDDisplayReset x"
Expect: expect/reset-pin-bad
RC: 1

Test: The brightness is kept although there is no backlight to drive
Args: --command "LCDDisplayBrightness 50" --command "LCDDisplayOn"
Expect: expect/brightness
